# Daud Fabrics — E-Commerce Website

A modern, fully responsive e-commerce website built for **Daud Fabrics**, providing an elegant online shopping experience for premium fabrics, shawls, traditional clothing, and related products.

The project includes both the **customer-facing online store** and a **secure administrative management system**, with responsive layouts optimized for mobile phones, tablets, laptops, and desktop computers.

---

## ✨ Features

### 🛍️ Customer Store

- Modern e-commerce homepage
- Product catalog
- Product categories
- Men's collection
- Women's collection
- Gents collection
- Seasonal collections
- Product detail pages
- Product images and galleries
- Product pricing
- Discounted products
- Product ratings and reviews
- Add to cart functionality
- Shopping cart
- Responsive product grids
- Search and navigation
- Contact page
- Customer account area

### 👤 Customer Accounts

- Customer authentication
- Login
- Account dashboard
- Customer profile
- Order-related functionality
- Protected account pages

### 🔐 Admin System

- Secure admin authentication
- Protected admin dashboard
- Admin-only access
- Cookie-based authentication
- Environment-based configuration
- Administrative management features
- Protected routes using middleware/server-side authorization

### 📱 Responsive Design

The entire website is designed to work across:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop computers
- 🖥️ Large displays

Layouts, navigation, product cards, buttons, forms, images, dashboards, and other components adapt to different screen sizes.
